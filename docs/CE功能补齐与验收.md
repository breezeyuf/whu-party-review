## 已完成

| 范围 | 使用入口和行为 |
| --- | --- |
| C 档案资料 | 发展档案详情“编辑”：维护姓名、性别、民族、出生日期、籍贯、专业、班级、支部、批次和扩展资料；校验日期与组织权限，失败保留输入；资料更改使旧报告失效。新建档案也补入民族、出生日期、籍贯。 |
| C 锁定节点 | 组织部身份可更正锁定的档案时间节点，必须填写原因；其他身份保持只读，原有审计和权限检查保留。 |
| E 身份授权 | 用户编辑支持多条“角色 + 组织”授权；校验重复及管理范围。只修改用户资料时不发送 roles，避免整体替换导致丢失原授权。 |
| E 批次管理 | 五级截止日完整维护、状态选择及关闭批次入口；已有档案时可关闭并保留记录。日期、年度及阶段输入有校验。 |
| E 规则试运行 | 提交包选择与临时规则 JSON 参数、级别、启停覆盖；显示具体新增和消失问题。后端基于脱离数据库的固定快照执行完整性、时间、形式、内容四类规则检查，不落库、不调用大模型，语义检查不计入“消失”。 |
| E 规则配置 | 日期到节点映射、来源材料、必需起始阶段、派生表达式及排序；区间枚举修正为 DATE_RANGE；支持清空阶段和派生表达式。 |
| E 统计导出 | 组织、批次、阶段和日期筛选；高频问题按规则/类别/材料类型切换；AI 效能增加材料类型分析；导出使用实际阶段、学院、批次和日期控件，显示任务及下载错误。 |
| E 系统设置 | AI、OCR、上传、保留期、通知、日历、安全及 worker 分组维护；按身份限制编辑，数值和日期数组校验，保留空密钥/显式清除密钥，失败保留输入。OCR 测试实际识别内置图片，未安装引擎时明确失败。 |

用户明确排除的“E＋后端”：加密的一次性批量密码文件交付没有纳入此次改动。原有导入结果展示和复制保持原状。共享服务器部署、邮件短信实际投递、真实 OCR 模型安装及联网多人部署不属于此次本地程序交付。
