# 党员发展材料智能审核工作台

全栈项目：`frontend/` 为 React 工作台，`backend/` 为 FastAPI + PostgreSQL。

## 前端

React 19 + React Router 7 + Vite 8 + Tailwind CSS 4 + daisyUI 5（本地依赖，主题 `nord`）。页面与 DESIGN.md 路由对应，接口前缀 `/api`。

```bash
cd frontend && npm install && npm run dev
npm run build   # 产物 dist/，由后端同源托管
```

## 后端

FastAPI 入口 `backend/main.py`（`app = FastAPI()`），端口读 `PORT`（缺省 8000）。启动时执行 `schema.sql` 建表、写入默认规则、确保管理员账号，并启动后台 worker。

```bash
cd backend
pip install -r requirements.txt
python main.py
```

数据库为 PostgreSQL，连接串见 `docs/RUN.md`。`storage/` 存放材料原件与预览，不对外静态开放。

## 联调

开发时 Vite 代理 `/api` → 后端。生产构建后由 FastAPI 挂载 `frontend/dist`，浏览器只访问后端端口即可。
