# OCR 模型复核与界面验收

接口采用可配置的 Chat Completions 基础地址、模型和独立密钥。文字模型用于文本任务，视觉复核模型必须支持图片输入。DeepSeek 曾实测返回可解析结果；其他服务未实测，不宣称全部兼容。更换服务后重新保存该服务密钥，并先测试内置虚构样例。

连接测试验证内置图片的关键文字，不以模型未提供置信度判失败，也不证明真实材料准确率。缺失置信度标记为未提供，原文保留；截断输出拒绝采纳。

## 虚构样例与预期

| 本地原文 / 建议 | 验证点 |
|---|---|
| 抗5战胜利80周年 / 抗战胜利80周年 | 标记删除的5，数字变化提示，核对确认后才填入 |
| 完整两段文字 / 只剩首句 | 明显缩短提示；不自动覆盖原文 |
| 2026年9月15日 / 2025年9月15日 | 数字变化提示 |
| 测试甲 / 测试乙 | 对比区域标出姓名差异，必须对照原图判断 |
| 完全相同 | 不产生缩短或数字风险提示 |
| 模型响应finish_reason=length | 返回长度上限提示，保留本地结果 |

这些是可重复的模拟响应和界面防护测试，不是在线模型准确率评测。划掉文字与漏字的真实效果仍需逐行对照获准使用的代表样例，记录误改、漏改和完整性后再评价。检测缩短的阈值仅用于提醒，不自动判断建议是否正确。

## 网页操作

1. 系统配置：分组导航跳转到目标配置，独立保存后测试，未保存的输入不参与连接测试。
2. 我的材料：无需打开预览即可点击详情或删除；审核中不可删除；取消确认不发送删除请求。
3. 材料详情的解析文本：宽屏并排、窄屏上下查看本地原文和建议。高亮区是首尾相同内容之间的变化范围，可能包含未变化文字。
4. 数字变化或明显缩短的建议需勾选已核对原图，填入后尚未保存；保存并重新打开确认持久化。
5. 历史/只读材料不显示采纳或保存操作；人工校正后原始OCR证据仍保留。
