# 大模型请求脱敏修复

本次完成桌面分工中 D 负责的一项工作：将已有脱敏函数接入实际的大模型请求。修改位于分支 `fix/llm-desensitization`，基于 `dev`。

## 行为变化

- 内容审核将当前学生档案传给模型请求入口，供姓名和学号精确替换使用。
- 脱敏默认开启：已知学生姓名、学号以及符合现有规则的手机号、18 位身份证号会替换成占位符。
- 先处理完整文本再截取每个变量的 6000 字符上限，避免身份信息恰好跨越截断位置时留下原文片段。
- 统一处理普通模板、无模板时的 JSON 请求，以及最终的系统提示词和用户提示词。
- 使用副本生成请求，原始材料正文和传入变量保持不变；不将模型返回的占位符自动还原为身份信息。
- 沿用现有配置：`ai.desensitize=false` 明确关闭时不执行脱敏；模型未配置时不发起请求。

姓名与学号替换依赖当前学生档案，其他人的姓名、地址等自由文本信息不在本次自动处理范围内。这项修复不等同于对材料进行全面匿名化。

## 验证

新增 `backend/tests/test_llm_desensitize.py`，用虚构身份与 HTTP 模拟接口检查实际请求内容，不连接真实模型或数据库。覆盖默认脱敏、档案上下文、提示词、嵌套变量、原文不变、截断边界、配置关闭和未配置模型等场景。
