# 原文框选与节点抽取校正

补齐设计中的两项审核操作：在材料原文预览上拖框新增问题，以及对材料的时间节点抽取记录逐条新增、修改、删除。

## 使用方法

1. 有当前审核权限的身份进入审核工作区，选择材料当前版本，点击“框选新增问题”，拖动选中原文区域，松开后填写并保存问题。问题保存材料、版本、页码和原文坐标，重新打开可定位。
2. 进入材料详情的“解析文本”，在“时间节点抽取”中新增、修改或删除记录，填写校正原因，再选择“保存校正”或“保存并重新校验”。支持日期、日期区间、序列和学时。

框选支持缩放后的坐标换算、反向拖动与 Esc 取消。更换材料或版本时清除旧框选，后端校验材料归属、版本、页码及矩形范围。

节点校正在全部输入通过校验后执行，拒绝无效日期、倒序区间、负学时、非法序号及跨材料版本的记录。删除停用记录并保留审计，新增和修改标记为人工校正；保存后重新合并档案节点并使旧报告失效。

学生、历史版本及无当前层级权限的身份只读。新增功能使用既有问题和解析校正接口，不需要新增数据库字段。
