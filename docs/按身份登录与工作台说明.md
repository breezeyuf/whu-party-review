# 按身份登录与专属工作台

> 阶段记录：本文记录 2026-10-19 的前端身份隔离交付及当时的测试结果。后续真实本地数据库、桌面窗口和业务闭环验证见 [2026-10-20 Windows 成品验收](Windows本地程序验收.md)，本地运行方法见 [Windows 使用说明](Windows本地程序使用说明.md)。

2026-10-19。本次根据“登录后只显示对应身份的界面，如管理员和申请学生”的要求，修改当前项目的真实前端及独立预览。

## 登录后看到什么

| 账号身份 | 默认首页 | 页面和菜单 |
| --- | --- | --- |
| 申请学生 `STUDENT` | `/student` | 我的材料、自查提交、整改、发展进度、消息 |
| 支部／互查／学院审核员 | `/review` | 审核待办、发展档案，以及权限范围内的业务、规则和统计 |
| 系统管理员 `SYS_ADMIN` | `/admin` | 用户管理、组织架构、系统配置、审计日志和统计 |
| 组织管理员 `ORG_ADMIN` | `/admin` | 组织和批次管理，以及原有权限允许的备案、档案、规则、统计等事项 |

单身份账号登录后直接进入自己的工作台。多身份账号通过密码验证后，先选择一个已被授权的身份；选项来自 `/auth/me` 返回的账号角色，不提供自行获得管理员权限的入口。相同角色位于不同组织时，分别显示组织名称。

进入工作台后，顶部显示当前身份，移除角色切换下拉框。多身份用户需要退出并重新登录，再选择本次办理身份。普通页面的个人中心只显示本次身份及组织。

原有 `/` 地址会导向当前身份首页。直接进入其他身份的首页会返回自己的首页；直接进入没有权限的业务地址会显示无权访问，且不挂载目标业务页面。首次强制改密优先于工作台和身份选择。

## 权限与会话处理

- 学生专属 `/my/*` 页面补上学生角色限制；管理、审核、档案、规则等原有权限限制继续生效。
- 材料详情只对学生和具备材料审核权限的业务角色开放，具体材料和组织范围由后端继续校验。
- 新登录先清除上一账号的角色信息，再向服务端查询真实身份。身份查询失败会清除本次令牌，不进入半登录状态。
- 选择身份先验证账号拥有该角色，再请求服务端确认；验证失败保留选择页并恢复之前的角色头，允许重试。
- 页面重新加载时恢复已选择的身份和组织；多身份但尚未选择的会话仍回到选择页。
- 用户或身份变化会重新挂载工作台，释放上一身份的页面数据和轮询。

本次没有修改后端授权规则、角色分配、接口或数据库。前端路由负责界面访问，服务端继续校验令牌、角色归属和数据范围。消息及个人资料仍是登录账号的公共入口。

## 在本机体验

双击外层 `预览新版界面.cmd`，或仓库根目录 `preview-ui.cmd`。当前已启动服务也可打开：

```text
http://127.0.0.1:5177/tests/design-preview.html
```

预览从统一登录页开始。展开“查看演示账号”可自动填入对应账号，点击“登录”进入；也可手动填写：

| 演示账号 | 身份 | 演示密码 |
| --- | --- | --- |
| `student` | 申请学生 | `Preview123!` |
| `admin` | 系统管理员 | `Preview123!` |
| `reviewer` | 支部审核员 | `Preview123!` |
| `multi` | 已授权的学生或支部审核员，登录后选择 | `Preview123!` |

以上仅是开发预览的虚构账号；预览使用生产前端同一套登录页和路由，所有接口和凭证保存在当前页面内存，不访问服务器，不读写正式账号凭证。刷新预览会回到登录页。部分业务仅展示入口，管理写操作不在预览范围内。正式账号登录请使用普通首页并启动团队后端与数据库。
