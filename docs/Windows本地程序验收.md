HTTP 回归覆盖首次强制改密、真实上传及解析、规则自查、报告过期拦截、整改重提、人工接管、支部／互查／学院／组织部流转与备案，以及 API 和 SPA 路由。使用合成资料验证业务接口，不作为真实材料审核结论。

前端界面逻辑未另行改写；此前 40 项 Node 回归与 42 项 React 交互结果仍记录在按身份登录说明中。此次生产构建重新生成并打包，浏览器直接连接 EXE 的真实本地 PostgreSQL 服务。

验收数据存放在交付目录之外的独立测试目录，与交付程序分离。交付包不包含测试账号密码、测试数据库和测试材料。用户第一次打开时会创建自己的独立数据目录和随机管理员初始密码。

## 交付范围

程序内置 Python、业务后端、React 生产页面和免安装 PostgreSQL。桌面窗口使用系统 WebView2；本机已实际验证。数据按身份和组织范围访问，监听仅限本机回环地址。

在线大模型和 PaddleOCR 模型不随包安装；扫描件按现有实现提示人工核对。当前成品面向单机运行，未作为多台电脑共享数据库的部署方案验证。

构建时将 PostgreSQL 放在单独的 `runtime/postgres/`，避免它的 DLL 干扰桌面窗口依赖。桌面适配只向后端增加资源目录配置，原有服务端运行方式及 PostgreSQL 授权、数据范围规则保留。程序的 `data/` 和 `demo-data/` 应连同密钥、材料完整备份；构建脚本遇到目标目录含用户数据时会拒绝覆盖。

使用方法、演示账号与备份方法见 [Windows 本地程序使用说明](Windows本地程序使用说明.md)。
