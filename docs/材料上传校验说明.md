# 材料上传校验

分支 `fix/material-upload-validation` 独立基于 `dev`。首次上传与补交新版本现在共用校验入口，统一遵守系统配置的大小限制与格式白名单，同时核对文件头。格式不符返回 415，超限返回 413；拒绝发生在文件落盘、版本变更和任务创建之前。

DOCX 额外检查 ZIP 文档包的必要结构，包括非空的 `[Content_Types].xml` 与 `word/document.xml`，拒绝损坏压缩包和改名为 DOCX 的普通 ZIP。这是结构检查，完整的文档可解析性仍由后续解析任务确认。

新增 17 项测试，覆盖首次及补交路径的禁用格式、扩展名与内容不符、体积超限、空文件、伪装或损坏 DOCX，以及正常 PDF 与真实 DOCX。文件写入被测试替身截获，不连接数据库。新增与相关原有测试共 32 项通过。
