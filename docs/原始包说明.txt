## 快速启动（Windows）

```powershell
# 1. 数据库（PostgreSQL 14+，建议 16）
createdb -U postgres party_review

# 2. 依赖
cd workspace\code
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
Copy-Item backend\.env.example backend\.env    # 填数据库地址/账号/密码

# 3. 恢复演示数据（推荐；不恢复也可在系统内初始化）
psql -U postgres -d party_review -f ..\..\数据库备份\party_review_20261017.sql

# 4. 启动
.\start.ps1        # 或双击 start.cmd
```

访问 http://127.0.0.1:8000 。演示账号 `demo_stu01`～`demo_stu24`、`demo_branch1`～`demo_branch6`、`demo_college1`～`demo_college2`、`demo_org`，统一密码 `Demo@2026`；管理员 `admin` 密码为本库初始化时设置的值（本项目为 `Admin@2026`）。
