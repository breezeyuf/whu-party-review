# 统计与导出修复

独立分支：`fix/stats-export-accuracy`，目标分支 `dev`。

## 行为变化

- AI 效能支持按提交包的批次、学院、支部、阶段和提交日期筛选。日期按 Asia/Shanghai 自然日计算，包含起止日；未提交的草稿不会落入日期范围。
- 高频问题和 AI 效能按材料类型代码合并不同材料的问题。未分类材料与未关联材料的问题分别统计。
- 规则和材料类型准确度以已处理问题（确认、驳回、修改）为分母，待处理问题不稀释准确度；没有人工处理记录时返回空值。
- 一次通过率定义为“已备案、只有一轮、没有退回记录的提交包 / 已备案提交包”。未完成审核的提交包不进入分母；分母为零时返回空值，并返回分子、分母及定义。
- 三类 Excel 导出均应用提交包筛选；服务端学院范围优先于客户端条件。脱敏导出以每个匹配提交包为一行，因此同一匿名档案的不同阶段可以分别出现。
- 统计导出增加汇总、阶段、支部、趋势工作表；AI 效能导出增加汇总与材料类型工作表；所有导出增加筛选说明。
- 明细不再静默截取前 5000 条，使用分批读取与只写工作簿；达到 Excel 单工作表行数上限时继续写入下一工作表。
- API 与后台导出均校验筛选格式；不支持的导出类型直接拒绝，不再退回默认报表。

## 验证

在独立的临时 PostgreSQL 16 数据库、随机测试 schema 中执行，未连接项目业务数据库：

```powershell
python -m pytest backend/tests/test_stats_export.py backend/tests/test_review_regressions.py -q
```

结果：42 项通过。新增用例覆盖同类不同材料聚合、待处理准确度、真实退回历史、北京时间边界、API 日期传递、三类导出筛选及学院范围、脱敏输出、5001 条真实提交包完整导出、错误筛选与导出类型拒绝。测试数据均为合成数据，随机 schema 测试后删除。

本次未调整前端统计页面的筛选入口；API 能力与已有导出页面提交的日期条件已接通。一次通过率的产品口径在此明确，团队可按验收需要另行调整。
