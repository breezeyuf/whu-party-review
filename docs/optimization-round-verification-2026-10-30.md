`desktop/verify-date-flow.py` 的 7 项检查全部通过：

4. 未确认区间不进入有效时间线。
5. 支部审核员核对、确认并排除不适用候选后，成为有效人工证据。

```powershell
python -X utf8 desktop/verify-date-flow.py --exe C:/PartyReviewQA/app/PartyReview.exe --data-dir C:/PartyReviewQA/new-date-data --output C:/PartyReviewQA/date-results.json
```
