# 工作台优先级修复记录（2026-10-26）

本次延续视觉 LLM OCR 复核功能，修复工作台核对清单中的缺项。提交在 `feature/ocr-workflow-integrated` 分支；本记录描述源码实现，不代表已合并主分支或替换桌面安装包。

## 已实现

| 项目 | 当前行为 |
| --- | --- |
| 空规则与版式检查 | 缺少参数或可验证证据显示 SKIPPED，不再当作通过。DOCX 检查继承样式、正文与表格文本的字体、字号、行距、节页边距；方向和装订侧余量按配置核对。 |
| 人工校正参与检查 | 内容、字段和字数检查使用人工校正值，包括主动清空。文本校正会重新提取字段，原始解析文本保留。时间节点仍需显式校正，不由文本修改暗中覆盖。 |
| 同批次相似度 | 查询同批次、同阶段、同类型的其他学生当前有效材料，排除本人及删除材料。只报告最高相似度，不向用户暴露他人原文或身份。无候选材料时跳过。 |
| OCR 失败与重试 | 实际 OCR 故障标记失败并保留部分解析诊断；不继续修改分类或提取时间节点。可编辑、未冻结的当前版本可以重新解析，重复请求复用排队任务，保留人工校正。 |
| 扫描质量 | 扫描 PDF 实际测量模糊程度，按 OCR 配置渲染。区分渲染 DPI 与可测量的源图 DPI，不把放大渲染误当成清晰原图。 |
| 签名与印章 | 结合文字定位签名/盖章区域，分别核对各必需位置，不用一个签名满足所有位置；候选结果必须人工研判。 |
| 长材料语义检查 | 内容检查与日期提取采用重叠分段，覆盖尾部；先脱敏再分段。经历核查带入档案时间节点。任一分段失败即放弃本轮部分语义结论。 |
| 基本信息一致性 | 姓名、学号、出生日期、性别、民族、籍贯和支部与档案核对；缺少档案基准时可提示同提交包材料间冲突，交人工核实。 |
| 邮件与短信 | 提供服务配置、加密凭据、配置完整性检查和后续适配接口；固定为 configuration_only，不连接服务或发送消息。站内消息保持原流程。 |
| 材料到期处理 | 按版本上传日期与保留年数生成待处理清单；管理员填写原因确认继续保留，写入审计记录。可查看已确认清单，重复确认不重复记账，原件不删除、不移动。 |

## 规则配置示例

在规则参数 JSON 中按实际制度配置，以下数值仅演示结构，不代表学校要求。

R-F08：`{"docx_layout":{"font":"宋体","size_pt":12,"line_spacing":1.5,"line_spacing_unit":"multiple","margin_cm":2.5}}`

R-F09：`{"orientation":"portrait","binding_side":"left","min_binding_margin_cm":2.5}`

R-C09：`{"references":[{"title":"示例规范","text":"经管理员核实的原文","source":"原文来源及版本"}]}`。仅核对明确归属于《标题》的引号内容。未配置来源、无可匹配引用或配置无效时跳过。

R-C10：`{"threshold":0.8}`。阈值须在 0 至 1 之间；相似度用于定位人工核查线索，不直接认定抄袭。

## 使用边界

- 签名与印章是图像线索，不鉴定身份、笔迹或真伪；扫描件无法可靠恢复的字体、装订余量等属性显示跳过。
- 相似度使用检查时的当前候选材料。新报告在规则结果中保存本次比较的算法、阈值、最高分、候选数量，以及每份候选材料的 SHA-256 文本指纹和原始比较分数；不保存其他学生的原文或身份。历史报告可按保存的分数复核当时结论。候选材料后来更新时，新发起的检查仍会使用更新后的材料，因此新旧报告可能不同；旧报告的比较证据保持不变。修复前生成的报告没有这份快照。
- 全文检查最多 40 段，超过上限明确失败并要求拆分；不返回截断后的通过结论。
- 视觉 OCR 模型需要管理员配置独立服务、密钥并允许图片上传；模型建议仍需人工对照原件确认，不保证所有手写内容准确。
- 邮件与短信的配置齐全不等于服务连通。真实投递按用户选择暂不启用。

## 第二轮：配置与数据保留的边界修复

- 清空模型或投递地址时，界面明确提交空值，避免显示清空而保存后仍使用旧地址；已有密钥的地址变更仍须重新填写或清除密钥。
- 非对象配置组及无效模型运行参数返回可读的校验错误，防止错误配置影响后续检查任务。
- 短信地址的非法括号、端口和空白字符均按配置错误处理；纯空白字段不再被误报为配置齐全。配置检查依然不连接或投递。
- 已确认保留清单展示确认人、确认时间和保留原因。清单减少后自动回到有效页，避免最后一页为空而前页还有记录。
- 审计日志中重新解析和确认保留显示中文动作名称。
- 重复保存文本时保留之前的人工字段覆盖和主动删除；文本派生的字段仍随文字更新。
- OCR 重试失败时保留此前的全文、页面、字段、视觉证据、页数及人工校正，明确提示本次失败。首次失败仍保存可用的部分解析。
- 同版本重解析保留人工时间节点，不再用自动值替换；按本版本的有序校正记录保留删除决定，并允许之后人工恢复。上传新版本仍按新版本来源更新。
- 无解析记录、无可比字段或缺少必要规则配置时返回 SKIPPED；无效数字和畸形参数不再产生虚假通过或中断整份报告。
- 禁用 OCR 时不等待其他任务；子进程返回的异常原文不进入材料诊断。视觉模型错误地址返回配置错误；显式模型温度 0 按保存值执行。

本轮验证：后端与桌面完整回归 608 项、前端逻辑 65 项、隔离接口样例的界面场景 78 项通过，生产构建成功。新增数据库场景使用独立测试库，不使用业务材料或发送外部消息。
