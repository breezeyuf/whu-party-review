# 工作台界面精简

> 历史阶段记录：本文记录 2026-10-19 的界面精简交付及当时的测试结果。后续登录入口已调整为[按身份进入专属工作台](按身份登录与工作台说明.md)；当前桌面运行方法和成品验收见 [Windows 使用说明](Windows本地程序使用说明.md)与 [2026-10-20 成品验收](Windows本地程序验收.md)。

本次根据“学生和审核员都精简”的选择，直接调整现有 React 工作台。重点是让使用者一进入页面就知道下一步做什么，并减少一次需要理解的菜单、筛选和表单。

## 实际变化

- 学生首页：一个主要办理入口，随待准备、可提交、退回、审核中和备案状态切换；实际材料完成率仍由接口计算。阶段全览和关键日期移到补充区。
- 审核员首页：待办数量和“开始审核”优先，旁边保留整改、截止提醒；统计和批次进度按需展开。
- 导航：学生保留五项日常入口；审核员默认显示工作台、审核待办、发展档案和消息四项。更多业务、规则、统计和管理可展开，进入相关页面时自动展开对应组。
- 审核列表：默认只显示任务范围、姓名学号和阶段三个筛选；其余放入“更多筛选”，已启用的条件会标明数量。勾选框和批量操作在选择“批量处理”后出现。
- 材料工作区：左侧原文、右侧问题和审核结论；顶部提供三个步骤定位。材料改用选择框，报告、时间轴、完整性和记录放在“参考资料”内。
- 问题：需要处理的阻断问题优先；规则编号、原文片段和定位详情按需展开。确认、驳回和修改操作仍直接可用。
- 审核决定：默认显示意见和主要决定；选择退回后才显示截止日期和关联问题，点击“确认退回”才调用原审核接口。
- 学生材料和整改：上传区缩短；每条问题的回复表单按需打开，已保存的回复仍可在问题中看到。
- 窄屏：导航收起为菜单按钮，支持 Escape 关闭；主要内容不产生页面级横向溢出。

业务权限、后端接口、问题处置、版本定位、报告过期拦截及审核流转继续使用现有实现。此次没有修改后端或数据库。

## 直接查看新版

在项目外层目录双击 `预览新版界面.cmd`，或在本仓库根目录双击 `preview-ui.cmd`。它使用开发服务器打开：

```text
http://127.0.0.1:5178/tests/design-preview.html
```

后续已按用户要求改为先登录再进入专属界面。登录页展开“查看演示账号”选择学生、管理员或审核员；退出后可体验其他身份，顶部不再排列不同身份的跳转入口。此入口使用明确标注的虚构数据，所有请求只在当前页面内存中处理，不使用真实登录令牌，不连接服务器，也不改写真实学生记录。该预览文件只用于开发，普通生产构建不会包含它。最新行为和检查结果见 [按身份登录说明](按身份登录与工作台说明.md)。

如果 5178 端口已被占用，使用现有服务，或在前端目录运行 `npm.cmd run dev` 后将终端显示的网址加上 `/tests/design-preview.html`。正式业务仍从普通首页登录并连接团队后端。
