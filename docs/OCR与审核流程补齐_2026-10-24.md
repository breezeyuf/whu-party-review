## 功能

- 本地 RapidOCR 3.10.0 + ONNX Runtime 1.31.0，Windows 程序打包默认检测、方向和识别模型。中文打印文字和日期已经实测；不需要配置聊天模型 API。auto 优先选择 RapidOCR，保留 PaddleOCR 兼容入口，none 关闭识别。设置的 OCR 超时实际生效，超时会回收识别子进程。
- 修复 OCR 图片像素坐标与 PDF 预览坐标不一致，扫描 PDF 和图片均转换坐标；系统设置中的识别测试包含中文。
- Excel 学生导入在 dry-run 阶段检查支部类型、可管理范围、出生和节点日期、节点代码、批次、现有账号组织状态。正式导入采用相同检查。
- 复核报告记录新增、移除、更新的材料版本；版本历史返回关联报告，界面展示追溯信息。
- 后台任务独立事务每 5 秒更新心跳；轮询间隔设置生效；过期导出同时清理磁盘文件。
- 截止提醒按五级截止日和当前办理状态发送站内消息，退回后提醒学生，互查按配对授权，停用账号和关闭批次不发送。按配置的提前天数触发，并以提交包、轮次、截止日、提醒日及接收人去重。
- 大模型低置信度分类兜底、遗漏日期节点补抽、建议润色已接入。输出按任务校验，补抽日期必须有原文证据，低置信度不采纳；润色必须保留模板要求。失败时保留规则或模板结果。
- RULE_LLM 同时运行规则及语义检查，规则证据与模型证据分开保留；模型调用使用并发限制，网络失败最多重试两次。
- 打包实测发现首次改密后立即登录存在提交时序问题，改密成功响应前现在显式提交事务。

## 安装与运行

源码环境使用 `python -m pip install -r backend/requirements-ocr.txt`，再按原开发说明启动。Windows 打包环境也必须先安装此文件中的依赖，再运行 `python desktop/build.py --output <新的输出目录>`。默认模型来自 RapidOCR 安装包，构建脚本自动收集模型和依赖；不需要把模型二进制提交到 Git。

当前本地程序位于 `C:/Users/19154/Documents/Codex/PartyReviewDesktopOCR20261024/PartyReview/PartyReview.exe`。根目录启动脚本更新后继续使用 CE20261023 的 data 目录，保留用户三个账号和已录入数据。不要用 StartDemo.cmd 验证正式账号。

模型服务配置在“系统设置 → 大模型”，填写兼容接口地址、模型名和密钥后测试、启用。对之前已经解析的材料，可以重新解析以应用模型分类和节点补抽。
